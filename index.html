Get SalahNest

Install it on your phone, read the source, or pick an older release.

  • Android app Version 1.6.5 · Final APK size pending · Android 7.0+ Android build pending
  • Source code malekmahmouda/prayer-times View on GitHub
  • All versions Latest: v1.6.5 View all releases

Straight to the GitHub release page — no redirects, no ads, no tracking. Android may ask you to confirm installing from outside Google Play.

Installing on Android

  1. Tap “Download for Android” — the APK comes straight from the GitHub release.
  2. Open the downloaded file. If Android asks, allow installs from this source.
  3. Grant notification permission so the adhan can reach you.

Or skip the download

This site is the whole app. Use “Add to Home Screen” or the install icon in the address bar and it runs offline after the first visit.
