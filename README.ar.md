# أوقات الصلاة · Prayer Times

رفيق إسلامي مكتبي (ويندوز) ومحمول (أندرويد) — أوقات الصلاة، القرآن، الأذكار، القبلة، والمزيد، بجوهر يعمل دون اتصال بالإنترنت.

🌐 **تطبيق الويب:** https://malekmahmouda.github.io/prayer-times/ — تطبيق ويب قابل للتثبيت (PWA)، يعمل دون اتصال بالكامل بعد أول زيارة.

📥 **التنزيلات:** أحدث [الإصدارات](https://github.com/MalekMahmouda/prayer-times/releases) — مثبّت ويندوز + حزمة أندرويد موقّعة.

## المزايا

**محرّك الصلوات (دون اتصال، بلا حساب، بلا تتبّع)**
- حساب أوقات الصلاة محليًا عبر مكتبة [adhan](https://github.com/batoulapps/adhan-js) — 8 طرق حساب + المذهب (الشافعي/الحنفي)
- جدولة في العملية الرئيسية: حلقة إطلاق كل 30 ثانية مع سماحية النوم/الاستئناف، وانتقال اليوم، وإزاحة الدقائق لكل صلاة
- إشعارات ويندوز الأصلية، وتنبيهات ما قبل الأذان لكل صلاة
- شاشة أذان بملء الشاشة مع اختيار المؤذّن ومستوى الصوت والتشغيل/الإيقاف
- عرض يراعي المنطقة الزمنية للمواقع المحفوظة

**المحتوى الإسلامي**
- 📖 قارئ القرآن — مصحف بأسلوب تطبيق «سورة»: نص عثماني موثّق (من إصدار تنزيل) مع ترجمة صحيح إنترناشونال، 114 سورة / 6236 آية، بحث دون اتصال (عربي + إنجليزي)، علامات مرجعية مع ملاحظات، وتحكّم بحجم الخط وتباعد الأسطر ووضع ليلي
- 🎧 مشغّل صوتي — 5 قرّاء مع تشغيل خلفي عبر الصفحات
- 📿 مكتبة الأذكار — أذكار الصباح والمساء وبعد الصلاة والنوم والعامة، مفضلات، عدّاد بأهداف وتقدّم
- 🌙 أسماء الله الحسنى (99) مع بحث
- 🕌 بوصلة القبلة مع الاتجاه والمسافة إلى الكعبة
- 🌅 أوقات الشمس والليل — الشروق والغروب والظهيرة شمسيًا ومنتصف الليل والثلث الأخير
- 📅 تقويم شهري بتواريخ هجرية وتصدير CSV
- 🌙 وضع رمضان — عدّاد الإفطار، مؤشر يوم الصيام، وتقدير الإمساك

**الشخصي (كله محلي)**
- سجل الصلوات بتسجيل ثلاثي الحالات → إحصاءات مع سلاسل الإنجاز
- مواقع محفوظة متعددة مع تحكم بالتنشيط
- 8 سمات مدمجة + منشئ سمات مخصص
- نسخ احتياطي/استعادة بصيغة JSON مع تحقق
- الإنجليزية / العربية بتخطيط RTL كامل

**التكامل المكتبي**
- أيقونة شريط المهام مع عدّ تنازلي حيّ للصلاة القادمة
- الإغلاق إلى الشريط، البدء مع ويندوز، قفل النسخة الواحدة
- أداة مصغّرة دائمة الظهور ووضع مصغّر مدمج
- اختصارات لوحة المفاتيح (Ctrl+1–7 للصفحات، Ctrl+Shift+P للأداة، Ctrl+Shift+M للوضع المصغر)
- بلا شريط قوائم، وبلا أدوات تطوير في إصدارات الإنتاج

**واجهة المحمول (أندرويد)**
- شاشة رئيسية مخصصة: بطاقة متدرجة مع عدّ تنازلي حيّ وشريط صلوات قابل للتمرير
- تنقّل سفلي بخمسة تبويبات مع لوحة «المزيد»
- أهداف لمس بحجم مريح ونوافذ سفلية آمنة

## البدء

```bash
npm install
npm start
```

### بناء مثبّت ويندوز

```bash
npm run package:installer   # → dist/Prayer-Times-Setup-1.2.0.exe
npm run release             # → مجلد release/ مع بصمات SHA-256
```

### بناء حزمة أندرويد

```bash
npm run apk        # → release-apk/ (تتطلب JDK 17+ و Android SDK)
npm run web        # → dist-web/ (نسخة الويب PWA)
```

بيانات المستخدم تُحفظ في `%APPDATA%\Prayer Times` على ويندوز، وتبقى بعد الترقية وإزالة التثبيت.

## البنية

```
main/               العملية الرئيسية في إلكترون
├── main.js         دورة حياة النوافذ/الشريط، IPC، الإشعارات، الشاشة، الأداة
├── scheduler.js    مجدول الصلوات المرجعي (adhan): حلقة الإطلاق، استرجاع الفوائت، الإشعارات/الأذان/التنبيه المسبق
├── adhan-files.js  حل ملفات الأذان المحلية المرفقة (assets/adhans/ — يعمل دون اتصال)
├── tray.js         قائمة شريط المهام
└── json-store.js   مخزن إعدادات بلا اعتماديات خارجية
preload.js          جسر IPC آمن (contextIsolation + sandbox مفعّلان)
js/                 وحدات الواجهة (app, pages, pages3, reader, data, store3, overlay, widget)
styles/app.css      رموز التصميم، 8 سمات، واجهة زجاجية، خصائص منطقية لـ RTL
fonts/              خط Amiri Quran للمصحف (يعمل دون اتصال)
assets/adhans/     ملفات الأذان المرفقة (تعمل بدون إنترنت)
data/quran.json     نص القرآن الموثق + الترجمة (مضمّن)
```

نموذج الأمان: `contextIsolation: true`، `sandbox: true`، `nodeIntegration: false`، قنوات IPC مُتحقق منها، سياسة CSP في كل نافذة، وبلا نقاط تصحيح بعيدة.

## الخصوصية

كل ما هو شخصي — الإعدادات وسجل الصلوات والعلامات المرجعية والمواقع والسمات المخصصة — يُخزَّن محليًا على جهازك فقط. لا حسابات، لا تحليلات، لا تتبع.

أوقات الصلاة تُحسب **محليًا على جهازك** (المحرك نفسه يغذّي العرض والمجدول). ما يحتاج الشبكة:

- **البحث عن مدينة** — ترميز جغرافي عبر `api.aladhan.com` (إحداثيات فقط؛ الأوقات تُحسب محليًا بعدها)
- **صوت القرآن** — بث من `cdn.islamic.network`
- **صوت الأذان** — مرفق داخل التطبيق؛ النسخة الإلكترونية من `cdn.aladhan.com` بديل اختياري فقط إن غاب الملف المحلي
- **GPS** (في المتصفح) و**الترميز الجغرافي العكسي** عبر `nominatim.openstreetmap.org` لعرض اسم مدينتك

بدون إنترنت: أوقات الصلاة والإشعارات والأذان (الملف المرفق) ونص القرآن والبحث والأذكار والقبلة والتقويم والإحصاءات تعمل كلها.
